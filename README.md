# GitMount

**把 GitHub 仓库变成手机上的本地硬盘，电脑平板随时访问。**

GitMount 是一款 Android 应用，能把你的 GitHub 仓库（公开或私有）直接挂载成一个
**FTP / WebDAV 服务**。启动服务后，同一局域网内的电脑、平板、NAS、手机，都能用自带的
文件管理器直接访问这个仓库——浏览、下载、上传、新建文件夹、重命名、删除，所有操作
实时落到 GitHub 仓库本身，**手机上不需要维护任何同步副本**。

> 简单说：手机当服务器，GitHub 仓库当硬盘，整个局域网共享。

---

## ✨ 有哪些用处

- **手机当云盘服务器**：GitHub 仓库变身可读可写的网盘，想传文件就传，想删就删，
  不占用手机本地空间（仓库本身存在云端）。
- **私有仓库当家庭共享盘**：把私人仓库挂载出来，家里/办公室的设备都能访问，
  数据只在自己的 GitHub 账号里，不经过任何第三方中转。
- **Git 仓库直接当文件目录**：在任何支持 FTP 或 WebDAV 的文件管理器里，
  仓库看起来就是一个普通文件夹，不需要懂 Git 命令。
- **随时随地的代码/资料备份**：把重要目录直接丢进挂载出来的仓库，
  相当于自动"git 提交"到云端，外出也能用手机取回。
- **临时共享文件**：给同事发文件不用再压缩打包上传网盘，建个共享仓库，
  对方用文件管理器直接拖拽即可。

## 🎁 有哪些好处

- **零成本**：GitHub 免费账号即可使用，不需要买服务器、域名或云盘会员。
- **设备零门槛**：Windows、macOS、Linux、iPad、NAS 都自带 FTP/WebDAV 客户端，
  无需额外安装软件。
- **数据安全**：数据完全存放在你自己的 GitHub 仓库中；
  访问令牌用系统级密钥加密保存，应用不收集、不上传任何数据。
- **省电省心**：以前台服务运行，息屏、切后台也不断连；被系统误杀后可按你的
  意图自动恢复。
- **两种协议任选**：WebDAV（推荐）与 FTP（传统）都支持，兼容性广。

## 🖥 怎么用

1. 在 GitHub 生成一个访问令牌（勾选 `repo` 权限），或使用对目标仓库有
   `Contents` 读写权限的 Fine-grained token。
2. 打开 App，在设置里填入令牌、仓库名称，点"保存并初始化"。
   - 仓库不存在会自动创建为私有仓库，分支自动取默认分支。
3. 设置访问用的用户名与密码（局域网访问认证用，可与令牌不同）。
4. 返回主界面，启动服务，记下显示的 `http://手机IP:端口/`。
5. 在电脑上添加该地址（WebDAV）或 `ftp://手机IP:端口/`（FTP），
   用第 3 步的账号登录，即可像本地文件夹一样使用。

## 📋 适合谁

- 想在多台设备间共享文件，又不想付费购买云盘/ NAS 的个人用户
- 想把 GitHub 仓库当"活的文件夹"来用、省去本地同步步骤的开发者
- 需要快速给同事/朋友传递文件、又不愿意用第三方网盘的团队

## ⚠️ 需要了解的小知识

- 每次写入都会在 GitHub 仓库产生一次提交（git 机制如此，App 会自动生成提交说明）。
- 单文件建议不超过 95MB（GitHub Contents API 的限制）。
- API 配额为每小时 5000 次，大量小文件操作会消耗配额，App 已做缓存优化。
- 服务默认仅在局域网内可达；公网访问需自行配置路由器端口映射或内网穿透。
- FTP 为明文传输，适合可信局域网；对安全要求高时请优先使用 WebDAV。

## 🔒 安全说明

- GitHub 令牌使用 Android 系统级硬件密钥（Keystore）加密存储，明文不落盘。
- 访问密码仅保存在应用私有空间，不参与系统备份。
- 应用不联网收集任何信息，所有流量只指向 GitHub 官方 API。
