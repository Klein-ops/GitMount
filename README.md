# GitMount

**把 GitHub 仓库变成手机上的本地硬盘，电脑平板随时访问。多个挂载点，一个 App 全搞定。**

GitMount 是一款 Android 应用，能把你的一个或多个 GitHub 仓库（公开或私有）直接挂载成
**FTP / WebDAV 服务**。启动服务后，同一局域网内的电脑、平板、NAS、手机，都能用自带的
文件管理器直接访问这些仓库——浏览、下载、上传、新建文件夹、重命名、删除，所有操作
实时落到 GitHub 仓库本身，**手机上不需要维护任何同步副本**。

> 简单说：手机当服务器，GitHub 仓库当硬盘，整个局域网共享。

---

## ✨ 新版核心能力

- **多挂载点**：一个 App 同时挂载多个 GitHub 仓库，每个挂载点独立配置
  （仓库、协议、端口、访问账号、令牌），互不干扰。
- **全局服务一次启停**：主界面「启动服务」一次为**所有已启用挂载点**监听端口，
  不用逐账户分别开关；每个挂载点又有独立开关，想停哪个停哪个。
- **共享令牌 + 独立令牌**：所有挂载点默认共用一个 GitHub 令牌，挂载点令牌留空即
  自动继承；需要隔离权限时，可为单个挂载点单独填一个令牌。
- **匿名访问可选**：访问账号的用户名与密码同时留空即开启匿名模式，
  局域网内免登录直接访问（适合私密网络）。
- **GitHub API 余额提醒**：主界面实时显示本小时剩余 API 调用次数，
  心中有数不怕撞上限。
- **运行日志可分享**：日志卡片内置「分享」一键导出排查、「清空」重置；
  日志系统自动合并刷屏的重复条目，观感清爽。

## 🎁 有哪些好处

- **零成本**：GitHub 免费账号即可使用，不需要买服务器、域名或云盘会员。
- **设备零门槛**：Windows、macOS、Linux、iPad、NAS 都自带 FTP/WebDAV 客户端，
  无需额外安装软件。
- **数据安全**：数据完全存放在你自己的 GitHub 仓库中；
  访问令牌用系统级硬件密钥（Keystore）加密保存，应用不收集、不上传任何数据。
- **省电省心**：以前台服务运行，息屏、切后台也不断连；被系统误杀后可按你的
  意图自动恢复。
- **两种协议任选**：WebDAV（推荐）与 FTP（传统）都支持，每个挂载点可独立选择，
  兼容性广。
- **后台可控**：常驻通知可隐藏、可开启电池优化白名单、可配置打开 App 自动启动
  服务、可开启开机自启、可后台隐藏（最近任务不可见）、可仅本机访问不暴露局域网。

## 🖥 怎么用

1. 在 GitHub 生成一个访问令牌（勾选 `repo` 权限），或使用对目标仓库有
   `Contents` 读写权限的 Fine-grained token。
2. 打开 App → 右上角「设置」→ 完成可选的后台选项；进入「挂载点」页，
   把令牌填到**共享 GitHub 令牌**处（所有挂载点共用）。
3. 点右上角「＋」新建挂载点：填名称、选择/新建仓库、选协议（WebDAV/FTP）、
   端口，可单独填写访问账号（或留空启用匿名）。
4. 返回主界面，点「启动服务」——所有已启用挂载点同时就绪，
   记下各挂载点的 `http://手机IP:端口/` 或 `ftp://手机IP:端口/`。
5. 在电脑上添加对应地址，用第 3 步设置的账号登录（匿名模式免登录），
   即可像本地文件夹一样使用。

## 📋 适合谁

- 想在多台设备间共享文件，又不想付费购买云盘/ NAS 的个人用户
- 想把多个 GitHub 仓库当"活的文件夹"来用、省去本地同步步骤的开发者
- 需要快速给同事/朋友传递文件、又不愿意用第三方网盘的团队
- 需要同时挂载多个仓库、按仓库区分访问权限与端口的进阶用户

## ⚠️ 需要了解的小知识

- 每次写入都会在 GitHub 仓库产生一次提交（git 机制如此，App 会自动生成提交说明）。
- 单文件建议不超过 95MB（GitHub Contents API 的限制）。
- API 配额为每小时 5000 次（共享令牌与各挂载点共用）；大量小文件操作会消耗配额，
  App 已做缓存优化并在主界面显示本小时剩余次数。
- 服务默认仅在局域网内可达；公网访问需自行配置路由器端口映射或内网穿透。
- FTP 为明文传输，适合可信局域网；对安全要求高时请优先使用 WebDAV。

## 🔒 安全说明

- GitHub 令牌使用 Android 系统级硬件密钥（Keystore）加密存储，明文不落盘。
- 访问密码仅保存在应用私有空间，不参与系统备份。
- 应用不联网收集任何信息，所有流量只指向 GitHub 官方 API。
