## GitMount 1.2.0 正式版

### ✨ 新增
- 配置备份与恢复：一键导出/导入全部挂载点与设置，支持口令加密（默认加密）
- 访问控制升级：全局「强制仅本机访问」+ 每个挂载点独立「仅本机访问」开关两级控制
- 挂载点空闲回收：空闲超时（8 分钟）自动回收挂载点资源，多挂载点长期挂机更省电

### 🎨 优化
- 全局统一 Material 3 按钮规范：主操作 / 次级操作 / 危险操作（删除、清空历史）样式统一，消除按钮有边框无边框混用
- 挂载点开关（启用 / 仅本机访问）改为乐观更新：拨动立即翻转，不再卡顿等待落盘
- 运行日志默认折叠，点击展开查看完整内容
- 挂载点开关 / 编辑 / 删除改为增量同步：只启停变更的那个挂载点，不再全量重启服务、不打断其他挂载点的连接与传输
- 后台自启动自愈：进程被杀后重建不再干等系统调度，主动恢复服务

### 🔧 修复
- 修复匿名模式无法访问：新建挂载点用户名默认值改为空，避免残留用户名+空密码形成半配置状态被 FTP/WebDAV 拒绝
- 修复挂载点列表行 UI：仓库名过长时协议+端口被断行，锁定单行并超长省略
